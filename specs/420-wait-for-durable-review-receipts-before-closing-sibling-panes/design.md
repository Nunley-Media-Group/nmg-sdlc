# Design: Durable host review receipt collection

**Issue**: #420
**Date**: 2026-09-24
**Status**: Approved
**Author**: NMG

## Boundary and evidence

`runBoundedReview` in `scripts/sdlc-execute.mjs` owns sibling lifecycle. `inspectReviewReceipts` in `src/sdlc-review-isolation.mjs` is the existing authority for the exact assignment digest/invocation, host isolation module, read-only allowed paths, contamination, and final `review_result`; `parsedReviewResult` enforces the result delimiters. Do not change either validator or substitute agent output. The current loop waits, inspects, and closes one worker before touching the next; the review-step catch also closes remaining workers on error. Both paths must preserve all panes for missing/invalid receipt and worker failures. The separate, existing `invalid_review_slice` path for proven host contamination must retain its one owner-bound whole-stage replacement and original evidence.

The #129/#131 retained evidence and #141 issue comment show absent final receipts and controller pane closures; they do not record the instantaneous failed JSONL read or prove a single root cause. PR #422's one-pause fixture demonstrates an ordering bug, while its #131 live smoke still failed. Design a fixture that delays the host append across more than one observation and a second fixture that delivers a partial JSONL line before completing it; do not label these fixtures as proof of the historical throw site.

## Collection protocol

1. Launch/prompt slices as currently. Call `agentWait` and complete the existing state observation loop for **every** sibling before the first receipt inspection or pane close. An `agentWait` return while the worker remains `working` continues observation/pause until `idle` or `done`, without a settlement deadline. A failed, missing, blocked, or unknown worker fails and preserves all review panes/evidence; do not treat idle/done as evidence of a receipt.
2. Inspect each slice's existing assignment and exact host JSONL receipt path through `inspectReviewReceipts`. For incomplete/missing final host result, re-inspect the **same** path after `herdr.observationPause` at most 30 times (one second per pause), with no re-prompt, agent restart, new assignment, attempt, or invocation. The bound starts only after every sibling settles; a temporarily partial JSONL line may settle within this window. A valid complete nonempty `review_result` can terminate its observation early. Foreign receipts and wrong assignments never become acceptable; fail closed if observed. Persistent missing, malformed, foreign, wrong-assignment, or empty results fail without an aggregate artifact or handoff.
3. Stage validated nonempty results without closing any pane. On an unproven receipt or failed worker, leave *all* review panes owned/retained, keep assignment and JSONL bytes for diagnosis, write no aggregate `.md` or review handoff, and consume no `invalid_review_slice` allowance. Ensure review-step catch/stop cleanup cannot override this preservation. A completed, exact host receipt proving prohibited access is **not** a missing-receipt failure: preserve original evidence and use the existing `invalid_review_slice` path to consume one owner-bound replacement for the **whole** review stage, not one per slice. Missing/changed/consumed owner fails without replacement; failed replacement or second contamination stops without replenishment or a third attempt.
4. Only after all slices pass the exact-host checks without contamination, use the existing ordered aggregation (`No findings.` excluded when there are findings), review finalization, and owned-pane closure. Preserve the existing meaning of findings. The successful closure condition is all valid proofs/results, not merely terminal agent states; a pane-close failure remains an explicit failure with retained ownership for the affected pane. Do not weaken or replace the existing one-use recovery tests or original-evidence assertions.

## Verification contract for a later implementation

A focused pre-fix fixture must fail on premature inspection/closure or missing late result. Post-fix, `agentWait` returning while still working retains the unbounded worker-state observation loop; delayed result after multiple pauses (within 30) and a completed partial line pass using only the same host JSONL. Arrival beyond the bound and persistent missing/malformed/foreign/wrong-assignment/empty evidence or worker failure fail with no artifact/handoff, panes still present, and no recovery consumed. Proven prohibited access with a complete nonempty host result still takes exactly one whole-stage owner-bound replacement; retain existing regressions for original evidence, consumed allowance, failed replacement, absent/consumed owner, and second contamination without a third launch. Assert no pane closes while another worker remains unsettled or before every required receipt validates, including failure propagation through the controller catch; distinguish the existing contamination path from unproven evidence. Exercise the exact 30-pause ceiling without a wall-clock suite delay by driving the existing observation hook. Full suites/registered smoke belong to later implementation and cannot be reported passed by this spec draft.
