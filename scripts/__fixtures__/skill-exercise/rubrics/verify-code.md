# Verify-Code Skill Exercise Rubric

The verify-code exercise evaluates one deterministic artifact against the shared PR-dependent verification contract. Every criterion must pass; placeholder skips are not accepted.

| ID | Criterion |
|----|-----------|
| V1 | Pending readiness requires complete local scope, tests, and steering gates. |
| V2 | Every pending item uses an allowlisted kind, exact name, and AC mapping. |
| V3 | Satisfied evidence uses one exact successful head SHA and evidence links. |
| V4 | Partial, failed-gate, stale-scope, malformed, and unknown reports remain blocked. |
| V5 | Local report and issue comment preserve identical issue-scope evidence. |
| V6 | Ordinary Pass verification remains unchanged. |
