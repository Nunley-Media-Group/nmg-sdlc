# Open-PR Skill Exercise Rubric

The open-pr exercise evaluates ordinary delivery and the controlled draft H1/H2 transition. Every criterion must pass; placeholder skips are not accepted.

| ID | Criterion |
|----|-----------|
| P1 | Ordinary Pass keeps ordinary non-draft PR creation. |
| P2 | Qualified pending evidence completes every existing delivery-preparation gate before draft creation. |
| P3 | Draft reuse requires exact repository, base, head, issue, and draft identity. |
| P4 | H1 evidence succeeds before exact-head reverification. |
| P5 | A report push produces H2 and forces a complete evidence recheck. |
| P6 | The final H2 marker is validated before the ready transition. |
| P7 | Every failure preserves the branch/draft and emits no unsafe action. |
